Quickstart

From zero to a working desk. Assumes odm is on your PATH (Install).

First success path: complete steps 1–3 (init → Project + sync → status/doctor). Progen, actions, worktrees, and generate are optional next layers.

1. Init a Workspace

A Workspace is the on-disk root you work in. odm init creates .odm/odm.config.yaml (and git-inits the root by default).

mkdir my-desk && cd my-desk
odm init
# creates .odm/odm.config.yaml — empty projects/progens is valid

If the directory is already a Workspace (config present), init refuses — no silent overwrite. Use --no-git to skip git init. --interactive is reserved and not implemented yet.

2. Add a Project and sync

odm project add alpha --path projects/alpha --url <git-url>
odm sync
odm project list
  • Project = named path in config (usually a plain git clone).
  • sync materializes missing managed clones, then fetch only — never checkout/reset as part of sync.
  • Point at a specific root anytime: odm --root /path/to/desk …

Details: Projects & pins guide.

3. Status, pin, doctor

odm pin status
odm status
odm doctor
  • status — Workspace snapshot: presence, git/pin drift, worktree slots/orphans.
  • pin status / apply — optional lock of resolved SHAs (.odm/odm.lock.yaml). Apply checks out detached HEAD at the pin.
  • doctor — ODM-side health (config, paths, gitignore, orphans, dirty slots). Not store-content doctor.

Prefer --json for agents and scripts.

4. Progen memory

Add a docs/memory store (Markdown + index), reindex, and search:

# declare in config or:
odm progen add notes --path docs/notes
odm progen reindex
odm find "your query"
odm find "your query" --limit 5
odm context <note-id>

Guide: Progen memory.

5. Actions

Named shell tasks from Action bundle files pointed to by config:

odm run            # list actions
odm run <name>

Guide: Actions & generate.

6. Generate and worktrees

# Local template scaffold
odm generate
odm generate hello --dest out/hello
odm generate hello --dest out/hello --dry-run

# Parallel work on a Project (primary must be a git repo)
odm project worktree add alpha feat --branch odm-feat
odm project worktree list alpha
odm project git alpha --wt feat -- status

Worktree slots

Parallel trees under worktrees/<project>/<slot>/.

Generate

Local templates + --dry-run.

Offline dogfood (core-desk)

The repo ships an offline Workspace fixture. Prefer the full-tour script (fail-fast through sync, find, generate, …):

cargo build -p odm
./examples/core-desk/scripts/dogfood.sh
# or step manually:
cd examples/core-desk
odm --root . sync
odm progen reindex
odm find DeskUniqueToken
odm run hello
odm generate hello --dest out/hello

See examples/core-desk/README.md for worktree and prune dogfood depth.
