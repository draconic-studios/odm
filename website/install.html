Install

Get the odm binary on your PATH, then verify. Product overview is on the home page.

Success looks like: odm --version prints a version, then Quickstart bootstraps your first Workspace.

Requirements

  • Runtime: git on PATH
  • Actions (odm run): Unix shell
  • curl|sh install: curl, tar, POSIX-ish shell (macOS / Linux)
  • Build from source (contributors): Rust 1.70+

Quick install (primary)

One-liner installs a prebuilt binary from GitHub Releases via the canonical script on main:

curl -fsSL https://raw.githubusercontent.com/hembrow-innovations/odm/main/scripts/install.sh | sh
  • Default dir: ~/.local/bin (ensure it is on your PATH)
  • Integrity: SHA256 verified by install.sh (no cosign/minisign in v1)
  • ODM_VERSION=<tag> — pin a release instead of latest
  • ODM_INSTALL_DIR=<dir> — override install directory
ODM_VERSION=v0.1.1 curl -fsSL \
  https://raw.githubusercontent.com/hembrow-innovations/odm/main/scripts/install.sh | sh
ODM_INSTALL_DIR=/usr/local/bin curl -fsSL \
  https://raw.githubusercontent.com/hembrow-innovations/odm/main/scripts/install.sh | sh

Supported host triples

  • aarch64-apple-darwin
  • x86_64-apple-darwin
  • x86_64-unknown-linux-gnu
  • aarch64-unknown-linux-gnu

Unsupported OS/arch (including Windows) fails clearly — Windows is not a primary channel in v1.

Script: scripts/install.sh on main (raw URL above). Assets: four-platform tarballs + SHA256SUMS on GitHub Releases — first multi-platform cut is v0.1.1; default install uses latest. Contributors can still build from source.

GitHub Releases (direct download)

  1. Open github.com/hembrow-innovations/odm/releases (or v0.1.1)
  2. Download odm-<version>-<triple>.tar.gz for your host triple (prefer latest) and SHA256SUMS.
  3. Extract and place odm on your PATH (default recommendation: ~/.local/bin):
tar xzf odm-<version>-<triple>.tar.gz
# archive contains: odm, README-release.txt
mkdir -p ~/.local/bin
mv odm ~/.local/bin/
odm --version

For manual downloads, check SHA256 against the release SHA256SUMS. The install script does this automatically.

Verify

odm --version
odm init --help

If the shell cannot find odm, the binary is not on PATH yet — add the install directory and open a new shell.

Build from source (contributors)

git clone https://github.com/hembrow-innovations/odm.git
cd odm
cargo build -p odm --release
# → target/release/odm

cargo install --path crates/odm
# → ~/.cargo/bin/odm (typically)

Release tarball locally

./scripts/release-build.sh
# → dist/odm-<version>-<host-triple>.tar.gz
  • ODM_TARGET=<triple> — build for a specific triple
  • ODM_RELEASE_PUBLISH=1 — after build, run gh release create (authenticated gh)

Not in this release

  • Homebrew formula
  • crates.io publish of the binary crate
  • Signed/notarized macOS binaries (binaries are unsigned)
  • Windows as a primary supported channel
