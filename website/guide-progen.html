Progen memory

A Progen is a named docs/memory store: Markdown on disk + disposable index. ODM orchestrates many stores without pretending one vault is the world.

Engine (v0.1)

In-repo Obsidian-compatible vault engine: Markdown, YAML frontmatter, [[wikilinks]], SQLite FTS under .odm/progen/<name>/. Store content stays at the configured path — not inside .odm/.

Declare and lifecycle

odm progen add notes --path docs/notes
odm progen add eng --path apps/api/docs --url https://github.com/acme/api-docs.git
odm progen list
odm progen info notes
odm progen reindex
odm progen doctor

Git lifecycle for url entries matches Projects (sync/pin). Path may nest under a Project without merging the two entities.

Search and context

odm find "architecture"
odm find "architecture" --limit 5
odm find --progen notes "token"
odm find --progen-group core "token"
odm context <id>
odm context notes:<id>
odm context <id> --progen notes
  • find — federated FTS across scoped Progens; default = all configured. --limit is max hits per store (default 200).
  • FTS match — whole FTS5 tokens, not substring/prefix. Multi-word → AND of terms. CamelCase is one token (e.g. TodoWelcome does not match TodoWelcomeToken).
  • context — single-root in-store one-hop neighborhood only (no federation, no cross-store graph walk). Disambiguate with --progen / name:id when multiple stores.
  • Zero hits on find → exit 0, empty list.

Groups (scope aliases)

# in .odm/odm.config.yaml
progen_groups:
  core:
    - product
    - eng

Groups are config-only. Nothing is written into any store.

One store, one graph

  • Wikilinks/backlinks resolve only within that Progen.
  • No cross-store [[wikilink]] in v1.
  • Point outside with normal Markdown links (URL or path) — external, non-graph.

Store façade (single-root)

odm progen get <id>
odm progen body <id>
odm progen ls
odm progen tree
odm progen backlinks …

These façade verbs are single-root (pass --progen when multiple stores). Top-level odm find federates FTS; top-level odm context is single-root neighborhood — neither is an odm progen subcommand.

Many upstream-style verbs (task/issue/plan/watch/…) are reserved/deferred — not in the CLI today. See Features.
