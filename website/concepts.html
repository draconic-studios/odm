Concepts

Shared language for humans and agents. Full glossary: repo CONTEXT.md.

Workspace
The on-disk root you work in (or point at with --root), containing ODM config and state. Created for consumers by odm init. Distinct from the ODM product repository.
Avoid: monorepo root (when meaning the ODM-managed unit), installation, sandbox
Project
A named, config-declared path inside a Workspace, usually its own git checkout (plain clone). Only declared entries are Projects — not every subdirectory.
Avoid: submodule, package (when meaning a managed repo), repo (as the ODM entity name)
Progen
A named docs/memory store (Markdown on disk plus a disposable index) that ODM orchestrates at a config-declared path. Not owned by .odm/. Often its own git repo. Not a Project unless also declared as one.
Avoid: brain, knowledge base (as the product noun), vault (as the ODM entity name)
Progen group
A named, config-only grouping of Progen names used as a query/context scope. Not a store.
ODM state directory
The Workspace-local .odm/ tree holding ODM config and runtime state only (config, pin, caches, logs, ODM-side progen indexes). Does not own Project checkouts, Progen stores, worktree slots, or agent pack payloads.
Primary checkout
A Project’s main working tree at its config path. Implicit — not a separate config entity.
Worktree slot
A named, ODM-managed git worktree for parallel or agent work on a Project — separate from the Primary checkout. On disk at worktrees/<project>/<slot>/ (not under .odm/). Bound to a git branch.
Avoid: calling the slot itself a “branch” or “sandbox”
Agent pack
A portable bundle of agent-facing assets (skills, prompts, conventions) that ODM installs or links for coding agents. Not a Progen and not a Project.
Workspace config
The sole layout source of truth (canonically .odm/odm.config.yaml): Projects, Progens, groups, action/generator bundle pointers.
Pin file
Optional lock of resolved revisions for managed checkouts (.odm/odm.lock.yaml). Not layout truth; apply is explicit.
Action
A named task the CLI can invoke via odm run — Nx-task-like, not a built-in ODM verb. Defined in Action bundle files.
Generator
A named scaffold from a template package. Defined in Generator bundle files. Invoked with odm generate. Not an Action.

Mental model

<workspace>/
  .odm/
    odm.config.yaml      # layout truth
    odm.lock.yaml        # optional pins
    progen/<name>/       # indexes (ignored)
  worktrees/<project>/<slot>/
  projects/…             # Primary checkouts (where you declare them)
  docs/…                 # Progen stores (where you declare them)

Edge rule: Workspace config is the only layout source of truth. ODM never invents undeclared Projects or Progens.
