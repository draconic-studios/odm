Worktree slots

Parallel human or agent working trees on one Project without touching the Primary checkout.

Placement

worktrees/<project-name>/<slot-name>/

Not under .odm/. Usually gitignored when the Workspace is a repo. Each slot is a git worktree bound to a branch.

Lifecycle

# Prefer --branch when primary already has default branch checked out
odm project worktree add alpha feat --branch odm-feat
odm project worktree list alpha
odm project worktree rm alpha feat
odm project worktree rm alpha feat --force

# Orphan GC (empty dirs under worktrees/<project>/ that are not registered)
odm project worktree prune alpha
odm project worktree prune alpha --force
odm project worktree prune --all
odm project worktree prune --all --force
  • Primary must be a git repo.
  • Slot names: no path separators, no . / ...
  • Primary is never a slot — omit --wt to use Primary.
  • list reports registered slots only; each has dirty true/false/null.

Use a slot

odm project git alpha --wt feat -- status
odm run build --project alpha --wt feat
odm --project alpha --wt feat agent start -- true
odm status                 # shows slots + orphans
odm project info alpha

Missing slot with --wt → exit 4 (no auto-create). Pin auto-maintain stays Primary-only.

Observation vs cleanup

  • status / info — registered worktree_slots (with dirty) and worktree_orphans.
  • doctor — warns worktree_orphan:… and worktree_dirty:… (not fixable via --fix).
  • prune — explicit orphan GC. Default empties only; non-empty needs --force (exit 3 if leftovers without force).

Deferred: config-declared slots, branch templates, auto-prune on doctor, pin↔slot. See Features.
