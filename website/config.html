Reference

Config shape

Canonical file: .odm/odm.config.yaml. Full detail: docs/reference/config.md.

Top-level keys

  • name — optional Workspace label
  • manage_gitignore — bool, default true
  • projects — map name → Project entry
  • progens — map name → Progen entry
  • progen_groups — map name → list of Progen names
  • actions — map bundle name → path to Action bundle file
  • generators — map bundle name → path to Generator bundle file

Collections are maps keyed by name (not arrays). Keys use snake_case. Empty config is valid for bootstrap.

No top-level worktree slots or inline action bodies — actions/generators live in bundle files.

Example Workspace

name: my-desk
manage_gitignore: true

projects:
  api:
    path: apps/api
    url: https://github.com/acme/api.git
    branch: main
    type: service

progens:
  product:
    path: docs
  eng:
    path: apps/api/docs
    url: https://github.com/acme/api-docs.git

progen_groups:
  core:
    - product
    - eng

actions:
  core: actions/core.yaml

generators:
  core: generators/core.yaml

Project entry

  • path (required) — Primary checkout, relative to Workspace root
  • url (optional) — when set, git-managed
  • branch (optional) — clone checkout preference (not a pin)
  • type (optional) — metadata string

No submodule fields. Parallel remotes = separate entries.

Progen entry

  • path (required) — store root
  • url / branch — optional; same git lifecycle as Projects

Action bundle

# actions/core.yaml
bootstrap:
  tasks:
    - run: pnpm install
      dir: apps/api

Merge all bundles into one Action namespace; duplicate names → error. v1 task spine: run + optional dir.

Generator bundle

# generators/core.yaml
package:
  template: ./tooling/generators/package
adr:
  url: https://github.com/acme/gen-adr.git   # remote deferred at run time

If both template and url are set, prefer template.

Pin file (separate)

.odm/odm.lock.yaml — optional, fixed basename, not referenced from inside config. Created/maintained when Workspace is a git repo and managed clones succeed. Apply is explicit.
