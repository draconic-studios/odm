Reference

CLI surface

Single binary odm. Full depth lives in the repo docs/reference/cli.md — this page is the operator map.

Command tree

odm init
odm sync | pin | status | doctor
odm project …
odm progen …
odm find | context
odm run
odm generate …          # v1 local template
odm agent pack …        # v1 local install/link/list/rm
odm agent prompt …      # v1 thin (context work-package)
odm agent start …       # v1 one-shot exec

Global flags

  • --root <path> — Workspace root (must contain config)
  • --json — machine-readable stdout; human diagnostics on stderr
  • --project <name> — Project by config name
  • --progen <name> — Progen scope (repeatable)
  • --progen-group <name> — group scope (repeatable)
  • --wt <slot> — worktree slot path binding (needs Project context)

Core commands

odm init [<path>] [--no-git]

Bootstrap Workspace. Headless default. --interactive reserved/not implemented.

odm sync [name…]

Materialize + fetch managed entries. Never checkout as part of sync.

odm pin apply|status [name…]

Apply pins as detached HEAD; status vs HEAD.

odm status · odm doctor [--fix]

Snapshot (slots, orphans, packs) and ODM-side health checks.

odm project …

list | add | rm | info | git
worktree list|add|rm|prune|prune --all

odm progen …

list | add | rm | info
get | body | ls | tree | backlinks | reindex | doctor

odm find [query] [--limit <n>]

Federated FTS across scoped Progens (default = all). --limit max hits per store (default 200). Match is whole FTS5 tokens (not substring/prefix); multi-word → AND.

odm context <id>

Single-root in-store one-hop neighborhood only — not federated. Disambiguate with --progen / name:id.

odm run [action]

List or execute Actions. When executed, process exit code is the action’s exit code; pre-exec failures use ODM codes.

odm generate [name --dest …]

List or materialize local templates. Supports --dry-run, --force.

odm agent pack|prompt|start

Local packs (install/link/list/rm; source relative or absolute; --force overwrites dest); thin context package for agents; agent start one-shot exec of caller argv in a Project/--wt cwd (exit passthrough; no runtime matrix).

Exit codes

  • 0 success (including find with zero hits)
  • 1 usage / unknown / bad flags
  • 2 Workspace/config
  • 3 operation failed (git/pin/store and other ODM failures)
  • 4 not found

odm run passthrough: executed Actions return the action’s exit code, not always 3.

Always prefer --json for agents and automation. Human output may change; JSON shapes are the contract.
