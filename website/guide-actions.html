Actions & generate

Two different tools: Actions run named shell tasks; Generators copy local template trees.

Actions (odm run)

Workspace config points at bundle files; bundles define named tasks:

# .odm/odm.config.yaml
actions:
  core: actions/core.yaml

# actions/core.yaml
hello:
  tasks:
    - run: echo "hello from ODM"
bootstrap:
  tasks:
    - run: pnpm install
      dir: apps/api          # optional; default = Workspace root
odm run                 # list
odm run hello
odm run bootstrap --project api --wt feat
odm run hello --json    # envelope; task stdio captured
  • Actions are only invoked via run — never installed as top-level commands.
  • Duplicate action names across bundles → config error.
  • When executed, process exit code is the action’s exit code.
  • Unix shell required.

Generators (odm generate)

# .odm/odm.config.yaml
generators:
  core: generators/core.yaml

# generators/core.yaml
hello:
  template: ./templates/hello    # path relative to Workspace
odm generate                              # list
odm generate hello --dest out/hello       # materialize
odm generate hello --dest out/hello --dry-run
odm generate hello --dest out/hello --force   # non-empty dest
  • v1: recursive copy of a local template directory — no variable substitution.
  • --dest relative to Workspace root; must not escape.
  • --dry-run: same validation, zero writes; reports file count that would be copied.
  • Url-only generators list but fail on run (remote deferred).

Try both offline in examples/core-desk (odm run hello and odm generate hello --dest out/hello).
