# Progen scope and federation model

## Question

How do multiple progens participate in query/context — default all candidates, `--progen` single or list, named combinations only in ODM config, no cross-store linking inside a progen store — and how is that documented in `docs/reference/progen.md`?

## Blocked by

- [[issues-2-domain-glossary]]
- [[issues-3-research-progenitor-surface]]

## Answer

Documented in `docs/reference/progen.md`.

- Default read scope: all configured Progens; no default group field.
- Narrow: `--progen` (repeatable) and `--progen-group` (repeatable); union; names only.
- Writes: exactly one Progen (`--progen` or sole configured Progen).
- No cross-store `[[wikilink]]`; external refs via Markdown `[text](url|path)` only.
- Merge: tag hits with progen name; identity `(progen, id)`.
- ODM owns federation; progen crates stay single-root.
