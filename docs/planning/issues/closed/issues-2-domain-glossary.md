# Domain glossary for ODM redesign

## Answer

Canonical glossary locked in root `CONTEXT.md` (ODM context).

Terms: Workspace, Project, Progen, Progen group (not “combo”), ODM state directory, Primary checkout, Worktree slot, Agent pack (skills from repos or marketplaces), Workspace config, Pin file, Action (Nx-task-like).

Key boundaries: Progen ≠ Project (no dual registration required; Progen often its own git repo); path nesting allowed; branch stays plain git; Generator/layout/env deferred to sketch tickets.
