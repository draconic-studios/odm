# GitHub Actions: Pages + release publish only

Agents and humans must not treat every GitHub Actions workflow as forbidden. **Allowed:** GitHub Pages deploy of `website/`, and a **release publish** workflow triggered by tag `v*` and/or `workflow_dispatch` that builds multi-target assets and uploads them to GitHub Releases. **Still forbidden:** a product CI test matrix on PRs or every push (no full `cargo test` matrix as gate CI). Release publish is allowed so multi-platform binaries can ship without opening the door to PR gate CI; the test matrix stays local/dev-driven to keep agent and maintainer loops light.
